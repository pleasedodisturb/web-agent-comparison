# Web-Agent MCP Stage Walk — `browser-use`

You are driving the **browser-use** MCP against snapshot fixtures of Greenhouse +
Ashby job postings. Your job is to execute stages S1 through S8 using ONLY
the tools `mcp__browser-use__*`, `Read`, `Write`, and `Bash`. Save evidence to
`results/2026-05-28/browser-use/`.

**Output directory:** `results/2026-05-28/browser-use`

**Mock resume:** `fixtures/mock_resume.pdf`.

- Use ONLY `mcp__browser-use__*`, `Read`, `Write`, `Bash`. Never reach for

  MCP cannot fill a form), write `results/2026-05-28/browser-use/stage_sN.NA` (one line stating
