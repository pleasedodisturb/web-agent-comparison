## Goal

Stand up the single-command reproducibility surface (`make bench`) and the prerequisite gate that runs before any MCP touches anything. This plan lays the toolchain foundation that every subsequent plan in Phase 1 depends on. No MCP driver logic yet — that lands in plan 01-04 — but the Makefile target graph, the `check_prereqs.sh` gate, and the pinned dep closures (`uv.lock` + `package-lock.json`) are all wired so a clean clone can reach `make check` deterministically.

## Tasks

1. **Bootstrap the uv project.**
   - Write `pyproject.toml` with the spec above. `[project]` name `web-agent-comparison-harness`, version `0.1.0`, requires-python `>=3.12,<3.13`, deps as listed.
   - Add `[tool.uv]` section with `dev-dependencies = []`.
   - Run `uv lock` to produce `uv.lock`.
   - Write `.python-version` containing `3.12`.
   - **verify:** `uv sync --locked` exits 0; `.venv/bin/python -c "import mcp, anthropic, httpx, tiktoken; print('ok')"` prints `ok`.

2. **Bootstrap the npm project.**
   - Write `package.json` with `"private": true` and dev-dependencies as listed above. NOT regular `dependencies` — these are tools the harness invokes, not libraries it imports.
   - Run `npm install` to produce `package-lock.json` and populate `node_modules/`. Then run `npm audit signatures` per the global supply-chain hygiene rule; if it errors out (e.g., on `firecrawl-mcp` whose GitHub releases are dead per RESEARCH §6), capture the output to `package-audit.log` and continue — this is documentation, not a blocker.
   - Write `.nvmrc` containing `22`.
   - **verify:** `npm ci` (clean install from lockfile) exits 0; `npx -y -p @playwright/mcp@0.0.75 playwright-mcp --version` exits 0.

3. **Write `scripts/check_prereqs.sh`.**
   - Shebang `#!/usr/bin/env bash`, `set -euo pipefail`, `IFS=$'\n\t'`.
   - Define a `MISSING=0` counter and a `say_missing()` helper that prints `BIN: missing — install with: REMEDIATION` and increments MISSING.
   - Check host tools first: `jq`, `node`, `python3`, `uv`, `npm`. Remediation strings: `brew install jq`, `brew install node@22`, etc.
   - Then read `.mcp.json`: `for mcp in $(jq -r '.mcpServers | keys[]' .mcp.json); do CMD=$(jq -r ".mcpServers[\"$mcp\"].command" .mcp.json); command -v "$CMD" >/dev/null 2>&1 || say_missing "$CMD" "$(remediation_for "$mcp")"; done`.
   - Define `remediation_for` as a case statement mapping each MCP to its install command (per RESEARCH §1):
     - `playwright` → `npm install -g @playwright/mcp@0.0.75`
     - `browser-use` → `uv tool install browser-use==0.12.7`
     - `chrome-devtools` → `npm install -g chrome-devtools-mcp@1.0.1`
     - `lightpanda` → `download from github.com/lightpanda-io/browser/releases (nightly@2026-05-22 or v0.2.6)`
     - `obscura` → `npm install -g obscura-mcp@0.1.4-3 && obscura-mcp install`
     - `firecrawl` → `npm install -g firecrawl-mcp@3.17.0` (and a note about `FIRECRAWL_API_KEY`)
     - `cloakbrowser` → `uv tool install cloakbrowsermcp==2.0.4`
   - Also check `FIRECRAWL_API_KEY`: if unset, emit a WARNING (not an error — 6/7 is acceptable per PROJECT.md) and continue.
   - Final: if `MISSING > 0`, print summary line `check_prereqs: $MISSING missing` and `exit 1`. Otherwise print `check_prereqs: ok` and `exit 0`.
   - `chmod +x scripts/check_prereqs.sh`.
   - **verify:** `bash -n scripts/check_prereqs.sh` passes syntax; `scripts/check_prereqs.sh` runs end-to-end on Mac Mini and exits 0 (all 7 binaries installed per HANDOFF). Temporarily mv one binary out of PATH and re-run — must exit 1 with a remediation line.

4. **Write the Makefile.**
   - Header: `SHELL := /usr/bin/env bash` and `.SHELLFLAGS := -eu -o pipefail -c` so recipes fail loud.
   - Variables: `DATE := $(shell date -u +%Y-%m-%d)`, `MCPS := playwright browser-use chrome-devtools lightpanda obscura firecrawl cloakbrowser`, `RESULTS_DIR := results/$(DATE)`.
   - `.PHONY: bench check score clean coldstart stability tls $(addprefix bench-,$(MCPS))`.
   - `check:` target invokes `scripts/check_prereqs.sh`.
   - `bench:` depends on `check` and `$(addprefix bench-,$(MCPS))` and `score`. For Phase 1, only `bench-playwright` will resolve to real work; the other `bench-<mcp>` targets emit a "deferred to Phase 2" message and exit 0 so the surface compiles end-to-end without errors.
   - `bench-%:` target: `@scripts/run_mcp_session.sh $*` — this script doesn't exist yet (it's plan 01-04), so guard with `@test -x scripts/run_mcp_session.sh || { echo 'bench-$*: scripts/run_mcp_session.sh not yet installed (plan 01-04)'; exit 0; }`.
   - `score:` target: `@test -f $(RESULTS_DIR)/scores.json || { echo 'score: no scores.json at $(RESULTS_DIR) — run bench-<mcp> first'; exit 1; }` then `uv run python scoring/score.py $(RESULTS_DIR)/scores.json | tee -a $(RESULTS_DIR)/$(DATE)_run.md`.
   - `coldstart:`, `stability:`, `tls:` targets each emit `@echo "<target>: deferred to G-710 (scope cut 2026-05-22)"` and exit 0. The targets exist so the surface is locked.
   - `clean:` target: `rm -rf node_modules .venv __pycache__ */__pycache__ */*/__pycache__`.
   - **verify:** `make check` exits 0; `make bench-playwright` exits 0 (with the "not yet installed" warning since plan 01-04 hasn't run); `make -n bench` shows the expected target ordering with `check` first.

5. **Wire `.gitignore`.**
   - Append the entries listed above. Ensure `.mcp.json`, `uv.lock`, `package-lock.json`, `pyproject.toml`, `package.json` are NOT ignored.
   - **verify:** `git check-ignore -v .venv` reports ignored; `git check-ignore -v .mcp.json` reports NOT ignored (exit 1).

## Notes / Pitfalls

- **Pitfall 10 (version drift):** Lockfiles are committed; do not bump versions mid-phase. If `npm install` resolves a newer transitive than expected, investigate before committing the new lock.
- **Pitfall 11 (secrets):** `.gitignore` excludes `.env*` and `/tmp/firecrawl_api_token` (per HANDOFF-GSD-AUTO.md note about `~/.zshrc` auto-populating this path).
- **STACK §6 anti-pattern:** Don't `pip install` outside uv. The lock contract is `uv.lock` + `package-lock.json` — nothing else.
- **Mac-vs-Linux portability:** `scripts/check_prereqs.sh` should NOT use `gdate`, `gawk`, or GNU-specific extensions in this plan — host portability matters here for third-party reproducibility (PROJECT.md constraint). Bash 5+ + POSIX-ish flags only.
