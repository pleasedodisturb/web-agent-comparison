# Phase 3 reads it back, adds schema + payload, removes the deferred marker.

# Anthropic count_tokens reference (already a dep at anthropic 0.40.x):
# https://platform.claude.com/docs/en/build-with-claude/token-counting
# Call: client.messages.count_tokens(model="claude-...", messages=[...], tools=[...])
# Free API — separate rate limit; ANTHROPIC_API_KEY must be set in env.
# For schema scope: pass the tools_inventory.json tool list as `tools=` to count
# the prompt overhead Claude pays just to know the MCP's tool surface.

# Anti-pattern guard: do NOT call count_tokens on raw_stream.jsonl payload
# content. payload scope is bytes (proxy for tokens), not tokens. Per
# CONTEXT.md decisions: "schema is Anthropic-tokenizer-counted while payload
# is byte-count (proxy for token cost). Don't conflate the two units."

# Per-MCP browser-use-direct/agent share the same tool surface — schema_tokens
# is the SAME number for both rows (they share tools_inventory.json content).
# Compute once, write to both directories.

# Firecrawl payload note: firecrawl's payload IS its scrape result content
# (markdown blob). It can be much larger than other MCPs' tool_result payloads
# because firecrawl pre-extracts page content. This is the empirical finding,
# not a measurement artifact — record honestly.
